# TryHackMe Pre Security - Lessons Learned

## Overview

The TryHackMe Pre Security learning path provided a strong foundation in cybersecurity concepts, networking, web technologies, operating systems, and security fundamentals. This path helped build the essential knowledge required before moving into more advanced cybersecurity areas such as SOC operations, penetration testing, and threat detection.

---

# Key Lessons Learned

## 1. Introduction to Cyber Security

Cybersecurity is the practice of protecting systems, networks, applications, and data from unauthorised access, attacks, and damage.

Key concepts covered:

- Understanding the role of cybersecurity professionals
- Difference between offensive and defensive security
- Importance of protecting confidentiality, integrity, and availability (CIA Triad)
- Understanding common cyber threats and attack methods

**Key takeaway:**  
A strong security mindset starts with understanding how attackers think and how defenders can reduce risks.

---

# 2. Networking Fundamentals

Networking knowledge is essential for understanding how systems communicate and how attacks happen.

Topics covered:

- IP addresses and MAC addresses
- TCP/IP model
- OSI model
- Network protocols
- Ports and services
- DNS and HTTP/HTTPS communication

**Key takeaway:**  
Understanding normal network behaviour is critical for identifying suspicious activity during security monitoring and investigations.

---

# 3. How the Web Works

The web consists of multiple components working together, including browsers, servers, protocols, and applications.

Topics covered:

- Client-server architecture
- HTTP requests and responses
- Web servers
- Cookies and sessions
- Domain names and DNS resolution

**Key takeaway:**  
Understanding web communication helps security professionals identify vulnerabilities such as insecure configurations and web-based attacks.

---

# 4. Linux Fundamentals

Linux is widely used in cybersecurity, including servers, security tools, and penetration testing environments.

Skills developed:

- Navigating the Linux filesystem
- Using terminal commands
- File permissions
- User management
- Basic shell operations

Important commands:

- `ls`
- `cd`
- `pwd`
- `cat`
- `grep`
- `chmod`
- `sudo`

**Key takeaway:**  
Command-line skills are essential for security analysis, automation, and incident response.

---

# 5. Windows Fundamentals

Windows environments are common enterprise targets, making Windows knowledge important for security roles.

Topics covered:

- Windows architecture
- User accounts and permissions
- Registry basics
- Services
- Event logs
- Security features

**Key takeaway:**  
Understanding Windows internals helps analysts investigate suspicious activities and identify potential compromises.

# 6. Cybersecurity Principles

The path introduced important security concepts:

- Authentication and authorization
- Access control
- Encryption basics
- Vulnerabilities and exploits
- Security controls
- Risk management

**Key takeaway:**  
Security is built through multiple layers of protection rather than relying on a single defence mechanism.

# 7. Threats and Attack Techniques

Understanding attacker techniques is essential for building effective defences.

Topics covered:

- Phishing
- Malware
- Password attacks
- Social engineering
- Network attacks
- Vulnerability exploitation

**Key takeaway:**  
Knowing common attack methods allows defenders to detect, investigate, and respond more effectively.
